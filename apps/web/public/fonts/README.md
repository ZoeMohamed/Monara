# Nunito Sans

The User selected Nunito Sans on 12 October 2026. These are locally served, unmodified Google Fonts variable WOFF2 files, with normal and italic styles and weights 200 to 900. The Latin subset covers Monara's English interface and Indonesian text. Other scripts use system fallbacks.

Source: [Nunito Sans on Google Fonts](https://fonts.google.com/specimen/Nunito+Sans), retrieved from the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Nunito+Sans:ital,wght@0,200..900;1,200..900&display=swap).

The [SIL Open Font License](OFL.txt) is included. Next.js uses `next/font/local` for application pages; the standalone offline screen declares the same public font files directly. The service worker allowlists those two public paths, never arbitrary font URLs or personalized responses. No browser request to Google Fonts is needed.
