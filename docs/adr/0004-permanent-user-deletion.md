# Permanent User deletion

Deleting an account from Profile Settings means deleting the entire User identity and all its personal Monara data, including Financial Accounts, transactions, settings, connections, and conversations. Deletion is permanent after explicit confirmation, with no recovery grace period or undo: retaining a recoverable account would conflict with the requested complete removal. The confirmation must clearly explain that Monara cannot recover the deleted data.

Confirmation uses the existing authenticated session, the exact phrase `DELETE MY ACCOUNT`, an acknowledgement checkbox, and a final Delete permanently action; fresh Google authentication is not required. An accepted deletion immediately blocks access and background activity, with durable retries for cleanup failures: irreversible acceptance does not imply every storage system has already been erased. Completion requires all required cleanup to succeed, and signing in with the same Google identity afterward creates a fresh User with first-time onboarding.

Delete Monara-controlled personal data and revoke connections while preserving source Gmail emails, the Google account, already-delivered WhatsApp messages, and shared public merchant facts. Provider and backup retention limits must be disclosed accurately rather than promising erasure outside Monara's control. These decisions are accepted and implementation was explicitly authorized. The [User deletion design](../user-deletion-design.md) records the flow, retention boundaries, rollout requirements and local verification.
